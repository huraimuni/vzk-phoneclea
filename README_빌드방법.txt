VZK 폰클린 v1.0 - APK 만드는 방법
=====================================

이 폴더는 안드로이드 앱 소스입니다. 컴퓨터에 개발 도구를 깔지 않고,
GitHub이 대신 APK 파일을 만들어 주게 해 두었습니다. (무료)

[방법 A. GitHub으로 APK 받기 - 권장]
1. GitHub에 로그인하고 새 저장소를 만듭니다. (예: phoneclean, 공개/비공개 상관없음)
2. 이 폴더 안의 파일 전체를 저장소에 올립니다.
   - 웹에서 [Add file > Upload files]로 폴더째 끌어 놓으면 됩니다.
   - 숨김 폴더 .github 도 같이 올라가야 합니다. (안 올라가면 빌드가 시작되지 않음)
3. 올리면 자동으로 빌드가 시작됩니다. 저장소 위쪽 [Actions] 탭에서 확인합니다. (약 3~6분)
4. 초록색 체크가 뜨면 그 실행을 눌러 아래쪽 [Artifacts]의
   VZK-PhoneClean-APK 를 내려받고 압축을 풀면 VZK_PhoneClean_v1.0.apk 가 나옵니다.
5. 빨간 X로 실패하면 실패 화면을 캡처해서 보내 주세요. 고쳐 드립니다.

[방법 B. 안드로이드 스튜디오]
폴더를 [Open]으로 열고 Build > Build APK(s). (설치/동기화에 시간이 걸립니다)

[폰에 설치해서 테스트]
- APK를 폰으로 옮겨 열면 "출처를 알 수 없는 앱" 허용 안내가 뜹니다. 허용 후 설치합니다.
- 먼저 본인 폰에서 테스트해 보세요. 확인할 것:
  1) 앱이 열리고 목록이 나오는가
  2) 의심 앱이 상단에 뜨는가 (사이드로드한 앱, 접근성 켠 앱 등)
  3) [1단계 원클릭 일시 중지] 후 안내 창에서 [삭제할 앱 고르기]가 의심 앱을 미리 체크하는가
  3-1) 체크 후 [2단계 선택한 앱 삭제]에서 삭제 확인 창이 하나씩 뜨는가
  4) [광고·알고리즘 정리]의 각 버튼이 해당 설정 화면으로 가는가
  5) [결과 공유]가 카카오톡으로 넘어가는가

[알려드릴 점]
- 이 APK는 테스트용(debug 서명)입니다. 플레이스토어 등록용은 별도 서명 키가 필요합니다.
- 플레이스토어 등록 시 '설치된 앱 전체 목록 조회' 권한(QUERY_ALL_PACKAGES)은 구글 심사가 있습니다.
  심사에서 거절되면 카페를 통한 APK 직접 배포로 가야 합니다.
- 인터넷 권한이 없습니다. 점검 결과는 폰 밖으로 나가지 않고, 광고 설정/검색은 브라우저를 열어서 처리합니다.
- 문의는 카페 게시판으로만 받습니다. (앱 안에도 그렇게 안내)
