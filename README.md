# VZK 폰클린

광고로 자동 설치된 의심 앱을 찾아서 **1단계 일시 중지 → 2단계 삭제**까지 도와주는 안드로이드 앱입니다.

- 의심 앱 점수화 (설치 경로, 위험 권한, 숨김 아이콘, 몰려서 설치 등)
- 원클릭 일시 중지(백그라운드 종료, 임시 조치)
- 앱마다 삭제 확인 창을 연속으로 띄워 정리
- 광고·알고리즘 정리 안내
- 인터넷 권한 없음 (점검 결과가 밖으로 나가지 않음)

백신이 아니며 징후만 보고 판단합니다. 정상 앱이 의심으로 나올 수 있습니다.
